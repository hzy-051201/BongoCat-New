# BongoCat-New（增强修改版）

> 本项目基于 [ayangweb/BongoCat](https://github.com/ayangweb/BongoCat) 修改而来，**并非官方版本**。
> 发布时间仅提供 Windows 安装包（x64 / i686 / arm64）。
> 原版支持 Windows / macOS / Linux，完整使用说明与下载请见原版仓库。

原版是一个免费开源的跨平台互动桌宠：按键时猫咪会跟着敲键盘、移动鼠标时猫咪会看向光标。

本修改版聚焦 Windows 场景，在原版基础上**新增了以下功能**：

---

## 1. 强制移动鼠标（仅 Windows）

**作用**：在锁定或隐藏系统鼠标指针的 3D 游戏中，猫咪依然能正常跟随你的鼠标移动。
（原版在这种情况下会卡住不动，因为系统光标被游戏锁定，读数不再变化。比如第五人格等PC端游戏）

**说明**：

- 通过 Windows 原始输入（Raw Input）读取鼠标的**相对位移**，在应用内部维护一个用于显示的“虚拟光标”，再用它驱动模型的头部、眼球、爪子与鼠标贴图。
- **不会移动、不会干扰真实的系统光标**；关闭该选项后，行为与原版完全一致（跟随真实光标）。
- 适用于第一/第三人称射击等会锁定鼠标指针的游戏。
- 若游戏以管理员身份运行，请同样以管理员身份运行本应用（Windows 的权限隔离限制）。
- 位置：偏好设置 → 猫咪 → 模型设置 → 强制移动鼠标。

## 2. 鼠标移动速度

**作用**：调节“强制移动鼠标”的位移倍率（范围 0.25–4.00，默认 1.00）。

**说明**：数值越大，同样的鼠标移动会让猫咪跟随移动得更远，用于适配不同游戏内的鼠标灵敏度。开启“强制移动鼠标”后显示。

## 3. 键位图分组切换（standard 模型）

**作用**：为猫咪准备两套键盘按键贴图，用快捷键随时切换。

**快捷键**：

- `Ctrl + 3` / `Ctrl + 4` → 切换到 `resources/left-keys2/` 里的键位图
- `Ctrl + 1` / `Ctrl + 2` → 切换回 `resources/left-keys/` 里的键位图

**使用方法**：在模型目录的 `resources/` 下创建 `left-keys2` 文件夹，放入与 `left-keys` **同名的键位图**即可。
只放需要变化的键也可以，缺少的键会自动使用 `left-keys` 中的图片兜底。

> 示例：`<模型目录>/resources/left-keys2/KeyA.png`
> 对内置 standard 模型，目录为程序安装目录下的 `assets/models/standard/resources/left-keys2/`。

## 4. 动作与表情快捷键全局可用

**作用**：为模型的“动作”与“表情”绑定快捷键后，应用启动后**随时可用**。

**说明**：原版中这些快捷键只有保持“动作与表情”设置窗口打开时才生效；本修改版改为全局注册，无需打开任何窗口，直接在偏好设置 → 模型管理 →（动作与表情）中绑定快捷键即可。
